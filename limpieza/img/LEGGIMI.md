# Foto del sito

Salva qui le tue foto reali con questi nomi esatti. Appena il file esiste, sostituisce il riquadro grigio "Foto".

| File | Dove appare | Formato consigliato |
|---|---|---|
| `hero.jpg` | Portada | Verticale 4:5, almeno 1200×1500 px |
| `servizio-ordinaria.jpg` | Servizi · Pulizia ordinaria | Orizzontale 4:3, almeno 1200×900 px |
| `servizio-fondo.jpg` | Servizi · Pulizia a fondo | Orizzontale 4:3, almeno 1200×900 px |
| `servizio-vetri.jpg` | Servizi · Vetri interni | Orizzontale 4:3, almeno 1200×900 px |
| `fondatore.jpg` | Chi sono (la tua foto) | Verticale 3:4, almeno 900×1200 px |

Usa solo foto reali del tuo lavoro o con licenza d'uso, mai foto di stock presentate come lavori tuoi.
